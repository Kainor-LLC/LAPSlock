2. What LAPSlock is

LAPSlock is a client application that reads device inventory, local administrator passwords, and BitLocker recovery keys from Microsoft Entra ID and Microsoft Intune, using the Microsoft account you sign in with.

LAPSlock does not store your organization's data on any server we operate, and it grants no access you don't already have. Every request runs with your existing Microsoft permissions.
