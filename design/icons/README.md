# LAPSlock icon and wordmark

Everything here is generated by script. There is no design file, deliberately: a script
can be diffed, reviewed, and re-run at any size years from now, and it cannot be lost when
somebody's design tool subscription lapses.

## Two scripts, and only one of them makes shipping assets

| Script | Produces | Deps |
|---|---|---|
| `render-icon.py` | clean geometry, candidate sheets, wordmarks | Pillow |
| `texturize-icon.py` | **the shipping icon**, Entra logo, Icon Composer layers | Pillow + numpy |

`texturize-icon.py` imports `render-icon.py` and uses its geometry as the base, so the two
are a pipeline rather than alternatives.

```
python3 design/icons/texturize-icon.py <outdir> --synth     # shipping assets
python3 design/icons/render-icon.py    <outdir>             # candidates + wordmarks
```

**`render-icon.py` used to emit `AppIcon.appiconset` too, and no longer does.** Running it
would silently overwrite the shipping icon with the clean keycap, because its
`RECOMMENDED_MARK` still says `keyhole`. That constant is now historical and `main()` does
not call the shipping emitters. If you resurrect them, resurrect this warning with them.

## The mark that ships

**A keyhole inside a photoreal tire tread ring**, light on navy.
`SHIP_BASE = "tread"`, `SHIP_LIGHT = False` in `texturize-icon.py` are authoritative.

Decided 2026-08-29. The clean keycap that shipped before it read as one more entry in the
lock family; the tread ring is the mark nobody else in the category has, and it carries the
racing heritage the product was originally named for.

The realism is in the **shape of the stencil, not in shading**: pressure variation, ragged
rubber edges, ink starvation, edge spatter. The output stays a flat-colour stencil with no
baked gradients, shadows or blur, which is what makes it compatible with Icon Composer and
Liquid Glass — the system applies the material itself.

### Earlier attempts, recorded so nobody retries them

From `render-icon.py`'s own header, and worth repeating because each one looked promising:

- Sparse chunky tread blocks read as a **poker chip**.
- Sheared blocks read as a **camera shutter**.
- Herringbone chevrons read as the **recycle glyph**.
- Staggered block rows turned to **noise below 87 px**.

The fix was inverting the figure: a mostly-solid band with thin grooves *cut into* it reads
as tire; sparse blocks with big gaps never did.

Also rejected: a plain padlock, which failed both the 29x29 test and the "could be any
security app" test. `draw_padlock` survives in `render-icon.py` only so that comparison can
be redone rather than re-argued.

### Anti-goals

Two, both from real feedback, both permanent:

1. The product was renamed from **PitLAPS** because it reads as *armpit*.
2. The original icon — a top-down race car with a keyhole cockpit — read as **phallic**.

Check any new mark against both, with somebody else's eyes.

## Outputs and where they go

| File | Destination |
|---|---|
| `AppIcon.appiconset/` | `App/lapslock/lapslock/Assets.xcassets/` |
| `entra-logo-215.png` | Entra → App registrations → LAPSlock → Branding & properties |
| `iconcomposer-tread/` | Icon Composer layers, for the Liquid Glass icon |
| `wordmark-inline.png`, `wordmark-stacked.png` | site header, README |
| `proof-strip-*.png`, `comparison-sheet*.png` | not shipped, judgment only |

The asset catalog ships a **single 1024 image**. Xcode 14 and later derive every other size,
so one file is correct and one fewer thing to keep in sync.

Icons are written as RGB with **no alpha channel**. The App Store rejects an icon that has
one.

## Judge at 29 px, not at 1024

`proof-strip-shipping.png` renders the icon at 180, 120, 87, 60 and 29 points — the sizes
iOS actually draws. Regenerate and look at it after any change to the mark.

Judging an icon at 1024 is how you ship something that is mud on a home screen. That single
test is what killed the padlock version, and it is the reason the tread is a solid band with
grooves rather than separate blocks.

Known: at 29 px the tread reads as a distinctive textured ring rather than legibly as tire
tread. That is accepted — the silhouette is still unmistakable and the keyhole is still the
focal point. If it is ever revisited, enlarging the keyhole by 15–20% would buy legibility
at the smallest size.

## The Entra logo is not a minor asset

`entra-logo-215.png` is the image on the **consent screen** — the moment an administrator
decides whether to grant this app read access to every local administrator password in
their tenant. That single screen is the largest threat to this product, larger than price
or marketing.

215x215, under 100 KB, applied instantly with no build and no release. There is never a
good reason for it to be missing or stale.

## On the `--source` option

`texturize-icon.py --source FILE.png` can ingest a photo or scan of a real tire track
instead of synthesizing one. **Use CC0 or public-domain sources only.** Ordinary stock
licences commonly prohibit use in a logo or trademark, and this mark is intended for a
trademark filing.

The shipping asset is generated with `--synth`, which is seeded and reproducible and has no
licensing question attached to it.

## Changing the mark later is cheap

The app icon is PNGs in an asset catalog and ships with any ordinary app update. The Entra
logo is a single upload that applies instantly. Neither is locked in, unlike the bundle
identifier and the App Store name.

So it is worth doing well, and it is not worth agonising over.
